```bash

npm install
npx vite build          # הפלט: app/dist/index.html
cp dist/index.html ../index.html
```

`vite-plugin-singlefile` מטמיע את כל ה-JS, ה-CSS, הפונטים והאודיו לקובץ אחד.

## מסך הפתיחה — מכונת המזל

`app/src/components/invite/SlotIntro.tsx` + `app/src/lib/slotMachine3D.js`.

המכונה היא סצנת תלת־ממד חיה ב-[three.js](https://threejs.org) (רישיון MIT), לא ציור:
גוף פלסטיק עם clearcoat, מסגרת ומוט מתכת אמיתיים, מפת סביבה של אולפן שנוצרת
בזמן ריצה דרך `PMREMGenerator`, תאורת שלוש נקודות עם צל רך, וטון־מאפינג ACES.
הגלגלים הם גלילים אמיתיים עם טקסטורת קנבס שמסתובבים סביב הציר שלהם, מאחורי חור
שנחתך בגוף המכונה; במהירות גבוהה הטקסטורה מתחלפת בגרסה מרוחה — טשטוש תנועה.
הקליקים המכניים נוצרים ב-Web Audio בזמן אמת, בלי קבצי סאונד.

מבנה הסיבוב — נסיגה קלה לאחור לפני היציאה, האצה, מהירות קבועה, האטה, חריגה קטנה
מעבר לסמל ונעילה חזרה עליו, כשכל גלגל נעצר בתורו — מבוסס על
[slot-machine-gen](https://github.com/nuxy/slot-machine-gen) מאת Marc S. Brooks,
ברישיון MIT.

בדפדפן בלי WebGL, או כשמופעל `prefers-reduced-motion`, מסך הפתיחה מדלג ישר
להזמנה — כך שהיא עובדת בכל מקרה.
