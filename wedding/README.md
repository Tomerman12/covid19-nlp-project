ובשחרור הגלגלים מסתובבים ונעצרים על `28` · `10` · `26`. מיד אחר כך נפתחת ההזמנה

## מבנה

| נתיב | מה זה |
|---|---|
| `index.html` | **האתר עצמו** — בנוי, מוכן להעלאה. כל ה-JS, ה-CSS, הפונטים והאודיו מוטמעים בתוכו. |
| `media/` | המכונה: הקליפ ופריימי המשיכה. **חייב לעלות יחד עם `index.html`, באותה תיקייה.** |
| `app/` | קוד המקור (React + Vite) שממנו נבנה `index.html`. |

## איך בונים מחדש

```bash
cd app
npm install
npx vite build                 # הפלט: app/dist/index.html
cp dist/index.html ../index.html
```

`vite-plugin-singlefile` מטמיע את הקוד, הפונטים והאודיו לתוך `index.html`. קבצי
המכונה נשארים חיצוניים **בכוונה**, כדי שהדף ייפתח מיד ולא יחכה לשלושה מגהבייט של
וידאו. הם יושבים ב-`media/` בלבד; `app/public/media` הוא symlink לשם, כדי שגם
`npm run dev` וגם ה-build יראו אותם בלי להחזיק שני עותקים בגיט. כלומר: `media/`
לא נבנה מחדש ולא צריך להעתיק אותו — רק `index.html`.

## מסך הפתיחה — מכונת המזל

`app/src/components/invite/SlotIntro.tsx`.

המכונה **לא מצוירת ולא מרונדרת בזמן אמת** — היא רינדור פוטוריאליסטי שנוצר
ב-[Google Veo](https://deepmind.google/technologies/veo/) לפי תיאור העיצוב שלנו,
כולל הספרות `28` · `10` · `26` שנעולות על הגלגלים בקליפ עצמו. הקליפ מוצג כמו
תמונה ממוסגרת על נייר הקרם של ההזמנה — לא כרקע מלא מסך — כי קשת המכונה נוגעת
כמעט בקצה הפריים ואין שוליים להטמיע בהם את הקצה.

הקליפ המקורי הוא 16:9 ב-720p. `media/` מכיל חתיכה בגודל 960×720 ממנו
(`crop=960:720:230:0`), עם חידוד עדין, ובשני קידודים: VP9 לדפדפנים שתומכים
(קטן יותר) ו-H.264 כרשת ביטחון לספארי ותיק.

### איך המשיכה עובדת

הקליפ מחולק לשני חלקים שממשיכים אחד את השני **על אותו פריים בדיוק**:

| קובץ | מה זה | טווח בקליפ המקורי |
|---|---|---|
| `media/pull/01..24.jpg` | משיכת הידית — פריים לכל שלב | 0.54s – 1.04s |
| `media/machine.webm` / `.mp4` | הסיבוב, הנעילה, הנורות והקונפטי | 1.04s – 8.60s |

בזמן המשיכה הקומפוננטה צובעת לקנבס את הפריים שמתאים למקום שבו האצבע נמצאת, ככה
שהידית עוקבת **אחת־לאחת** ולא מנגנת תסריט קבוע — עם התנגדות גוברת מעבר לסוף
המהלך, קליק רַצֶ'ט כל שלושה שלבים, וחזרה בקפיץ אם לא משכו מספיק. פריימי המשיכה
נטענים מראש ונצבעים ב-`drawImage`; זו אותה טכניקה שאפל משתמשת בה בדפי המוצר
שלה, והיא מבטיחה מעקב מיידי בלי המתנה לפענוח או ל-`seek` של וידאו. הפריימים
עצמם נוצרו בהכפלת קצב הפריימים ל-48fps (`minterpolate`) כדי שהמשיכה תהיה חלקה.

בשחרור הווידאו מתחיל להתנגן מהפריים שבו המשיכה נגמרה, והקומפוננטה קוראת ממנו את
הזמן: שלוש חבטות הגלגלים ב-4.40 / 4.66 / 4.88, התאריך נחשף ב-5.02 כשהגלגלים
נעולים, והמעבר להזמנה ב-6.55 — בזמן שהקונפטי עוד יורד, ישר לתוך הקונפטי של
ההזמנה עצמה. הקליקים המכניים נוצרים ב-Web Audio בזמן אמת, בלי קבצי סאונד
(האודיו של הקליפ שקט לגמרי, אז הוא הוסר).

**כשמשהו לא עובד** — קודק חסר, רשת שנפלה, נגינה שנחסמה — יש רשת ביטחון אחת: אם
הווידאו לא זז בפועל תוך 900ms, התאריך מוצג על התמונה הדוממת וההזמנה נפתחת.
נגיעה בזמן הסיבוב מזרזת אותו (×2.6), ונגיעה אחרי שהתאריך נחשף מדלגת ישר להזמנה.
כשמופעל `prefers-reduced-motion` אין סיבוב בכלל: הווידאו נעצר על הפריים שבו
הגלגלים כבר נעולים, והתאריך מוצג מיד.
