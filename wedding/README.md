ובשחרור הגלגלים מסתובבים ונעצרים על `28` · `10` · `26`. מיד אחר כך נפתחת ההזמנה

## מבנה

| נתיב | מה זה |
|---|---|
| `index.html` | **האתר עצמו** — בנוי, מוכן להעלאה. כל ה-JS, ה-CSS, הפונטים והאודיו מוטמעים בתוכו. |
| `media/` | המכונה: הקליפ ופריימי המשיכה. **חייב לעלות יחד עם `index.html`, באותה תיקייה.** |
| `app/` | קוד המקור (React + Vite) שממנו נבנה `index.html`. |

## איך בונים מחדש

```bash
cd app
npm install
npx vite build                 # הפלט: app/dist/index.html
cp dist/index.html ../index.html
```

`vite-plugin-singlefile` מטמיע את הקוד, הפונטים והאודיו לתוך `index.html`. קבצי
המכונה נשארים חיצוניים **בכוונה**, כדי שהדף ייפתח מיד ולא יחכה לשלושה מגהבייט של
וידאו. הם יושבים ב-`media/` בלבד; `app/public/media` הוא symlink לשם, כדי שגם
`npm run dev` וגם ה-build יראו אותם בלי להחזיק שני עותקים בגיט. כלומר: `media/`
לא נבנה מחדש ולא צריך להעתיק אותו — רק `index.html`.

## מסך הפתיחה — מכונת המזל

`app/src/components/invite/SlotIntro.tsx` + `app/src/lib/reels.ts`.

המכונה היא **צילום, אבל לא סרטון.** המקור הוא רינדור פוטוריאליסטי שנוצר
ב-[Google Veo](https://deepmind.google/technologies/veo/) לפי תיאור העיצוב שלנו.
מהקליפ הזה נחתכו תמונות: המכונה הופרדה מרקע האולפן שלה לתמונות עם שקיפות, וחלון
הגלגלים נוקב בהן. התוצאה יושבת ישירות על נייר הקרם של ההזמנה — בלי מלבן, בלי
מסגרת, בלי רקע משלה.

| קובץ | מה זה |
|---|---|
| `media/machine/pull/01..31.webp` | הידית, פריים לכל שלב במשיכה |
| `media/machine/lit.webp` | אותה תנוחה, עם הנורות דולקות |
| `media/machine/meta.json` | מידות התמונה ומיקום החור של חלון הגלגלים |

### למה זה לא וידאו

וידאו מנגן תסריט קבוע: אותו אורך, אותה מהירות, ואי אפשר להתערב באמצע. כאן שני
החלקים שזזים הם קוד:

- **הידית** עוקבת אחרי האצבע אחת־לאחת. הקומפוננטה צובעת לקנבס את הפריים שמתאים
  למקום שבו האצבע נמצאת, עם התנגדות גוברת מעבר לסוף המהלך, קליק רַצֶ'ט כל שלושה
  שלבים, וחזרה בקפיץ אם לא משכו מספיק. הפריימים נטענים מראש ונצבעים ב-`drawImage`
  — אותה טכניקה שאפל משתמשת בה בדפי המוצר שלה, בלי המתנה לפענוח או ל-`seek`.
- **הגלגלים** מצוירים בקוד מתחת לחור (`reels.ts`): שלושה תופים על גליל אמיתי —
  המספרים מוקרנים לפי `sin`/`cos` של הזווית, כך שהשכנים מציצים מעל ומתחת, נמעכים
  ומתכהים לכיוון השפה. הסיבוב הוא נסיגה קלה לאחור, האצה, מהירות קבועה, האטה,
  חריגה מעבר לסמל ונעילה חזרה עליו, כשכל תוף נעצר בתורו. במהירות גבוהה הספרות
  נצבעות בכמה מעברים — טשטוש תנועה.

- **המכונה עצמה** חיה כל עוד הגלגלים מסתובבים: הגוף רועד (התנודה דועכת לאורך
  הסיבוב, ומקבלת בעיטה בכל פעם שתוף נתפס ובעיטה אחרונה כשהאחרון נעצר), הידית
  ממשיכה לחזור למנוחה בזמן שהגלגלים כבר במהירות מלאה, וקשת הנורות פועמת. בלי
  אלה זה נראה כמו חלון מונפש שהודבק לתוך צילום דומם.

הרעידה מוחלת על עטיפה שמכילה *גם* את המכונה וגם את הגלגלים, אחרת החלון היה נפרד
מהתופים. ההבהוב חתוך לקשת בלבד: הפריים המואר צולם בשנייה אחרת בקליפ ולכן הוא
בהיר ב-25% בכל הגוף — בלי החיתוך כל המכונה הייתה פועמת בבהירות במקום הנורות.

לכן: המשיכה חזקה יותר = סיבוב ארוך יותר, נגיעה באמצע מזרזת (×2.8), ונגיעה אחרי
שהתאריך נחשף מדלגת ישר להזמנה. הצבעים של התופים נדגמו מהרינדור עצמו כדי שיישבו
בתוך המסגרת המצולמת בלי תפר. הקליקים המכניים נוצרים ב-Web Audio, בלי קבצי סאונד.

הגלגלים מתחילים על `00 · 00 · 00` ונועלים על `28 · 10 · 26`. כשמופעל
`prefers-reduced-motion` אין סיבוב: התוצאה והנורות הדולקות מוצגות מיד.

## איך מעלים לאוויר

האתר סטטי לגמרי — אין שרת, אין build בזמן העלאה. מה שצריך לעלות זה **`index.html`
ו-`media/` בלבד**, באותה תיקייה. `.vercelignore` כבר דואג לזה.

### Vercel (מומלץ)

בדשבורד: **Add New → Project**, לבחור את הריפו, ואז:

| הגדרה | ערך |
|---|---|
| **Root Directory** | `wedding` ← **חובה.** שורש הריפו הוא פרויקט אחר לגמרי |
| Framework Preset | `Other` |
| Build Command | להשאיר ריק (אין `package.json` ב-`wedding/`, אז Vercel מגיש סטטי) |
| Output Directory | להשאיר ריק |

**שימו לב לענף.** Vercel מפרסם ל-production את ענף ברירת המחדל בלבד. אם העבודה
יושבת על ענף אחר, או שממזגים אותו ל-main, או ש-Settings → Git → Production Branch
מוגדר לענף הזה. אחרת ה-URL הראשי יראה משהו אחר, וההזמנה תהיה רק בכתובת ה-Preview.

מכאן כל `git push` לענף הזה מפרסם מחדש לבד.

### או משורת הפקודה

```bash
cd wedding
npx vercel            # תצוגה מקדימה
npx vercel --prod     # פרסום
```

מהתיקייה `wedding/`, כך ש-`.vercelignore` תופס. אין צורך להגדיר Root Directory.

### מה שולט בקאשינג

`vercel.json` נותן ל-`media/` יממה של קאש עם `stale-while-revalidate` שבוע,
ול-`index.html` אפס. הקבצים ב-`media/` הם בשמות קבועים ולא בשמות עם hash, אז
**אם מחליפים את תמונות המכונה, יכול לקחת עד יממה עד שגולש חוזר יראה את החדשות.**
מי שרוצה החלפה מיידית — לשנות את שם התיקייה (`machine` → `machine2`) ואת
`media(...)` ב-`SlotIntro.tsx`.

### GitHub Pages, אם בא לכם בלי Vercel

Settings → Pages → Source: `Deploy from a branch`, והכתובת תהיה
`https://<user>.github.io/<repo>/wedding/`. מעלים גם את `index.html` וגם את
`media/`.
