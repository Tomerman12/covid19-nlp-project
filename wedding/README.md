## איך בונים מחדש

```bash
cd app
npm install
npx vite build                 # הפלט: app/dist/index.html
cp dist/index.html ../index.html
```

`vite-plugin-singlefile` מטמיע את הקוד, הפונטים והאודיו לתוך `index.html`. קבצי
המכונה נשארים חיצוניים **בכוונה**, כדי שהדף ייפתח מיד ולא יחכה לשלושה מגהבייט של
וידאו. הם יושבים ב-`media/` בלבד; `app/public/media` הוא symlink לשם, כדי שגם
`npm run dev` וגם ה-build יראו אותם בלי להחזיק שני עותקים בגיט. כלומר: `media/`
לא נבנה מחדש ולא צריך להעתיק אותו — רק `index.html`.

## מסך הפתיחה — מכונת המזל

`app/src/components/invite/SlotIntro.tsx` + `app/src/lib/reels.ts`.

המכונה היא **צילום, אבל לא סרטון.** המקור הוא רינדור פוטוריאליסטי שנוצר
ב-[Google Veo](https://deepmind.google/technologies/veo/) לפי תיאור העיצוב שלנו.
מהקליפ הזה נחתכו תמונות: המכונה הופרדה מרקע האולפן שלה לתמונות עם שקיפות, וחלון
הגלגלים נוקב בהן. התוצאה יושבת ישירות על נייר הקרם של ההזמנה — בלי מלבן, בלי
מסגרת, בלי רקע משלה.

| קובץ | מה זה |
|---|---|
| `media/machine/pull/01..21.webp` | הידית, פריים לכל שלב במשיכה |
| `media/machine/lit.webp` | אותה תנוחה, עם הנורות דולקות |
| `media/machine/meta.json` | מידות התמונה ומיקום החור של חלון הגלגלים |

### למה זה לא וידאו

וידאו מנגן תסריט קבוע: אותו אורך, אותה מהירות, ואי אפשר להתערב באמצע. כאן שני
החלקים שזזים הם קוד:

- **הידית** עוקבת אחרי האצבע אחת־לאחת. הקומפוננטה צובעת לקנבס את הפריים שמתאים
  למקום שבו האצבע נמצאת, עם התנגדות גוברת מעבר לסוף המהלך, קליק רַצֶ'ט כל שלושה
  שלבים, וחזרה בקפיץ אם לא משכו מספיק. הפריימים נטענים מראש ונצבעים ב-`drawImage`
  — אותה טכניקה שאפל משתמשת בה בדפי המוצר שלה, בלי המתנה לפענוח או ל-`seek`.
- **הגלגלים** מצוירים בקוד מתחת לחור (`reels.ts`): שלושה תופים על גליל אמיתי —
  המספרים מוקרנים לפי `sin`/`cos` של הזווית, כך שהשכנים מציצים מעל ומתחת, נמעכים
  ומתכהים לכיוון השפה. הסיבוב הוא נסיגה קלה לאחור, האצה, מהירות קבועה, האטה,
  חריגה מעבר לסמל ונעילה חזרה עליו, כשכל תוף נעצר בתורו. במהירות גבוהה הספרות
  נצבעות בכמה מעברים — טשטוש תנועה.

לכן: המשיכה חזקה יותר = סיבוב ארוך יותר, נגיעה באמצע מזרזת (×2.8), ונגיעה אחרי
שהתאריך נחשף מדלגת ישר להזמנה. הצבעים של התופים נדגמו מהרינדור עצמו כדי שיישבו
בתוך המסגרת המצולמת בלי תפר. הקליקים המכניים נוצרים ב-Web Audio, בלי קבצי סאונד.

הגלגלים מתחילים על `00 · 00 · 00` ונועלים על `28 · 10 · 26`. כשמופעל
`prefers-reduced-motion` אין סיבוב: התוצאה והנורות הדולקות מוצגות מיד.
